¿Cómo se aplica CSS a los sliders en Power BI?

01

Quitar el estilo por defecto del browser

El primer paso es eliminar el aspecto nativo. Sin esto, el resto del CSS no funciona.

input[type=range] {
  -webkit-appearance: none; /* Chrome, Safari, Edge */
  appearance: none;         /* Firefox moderno      */
  background: transparent;  /* sin fondo por defecto*/
  width: 100%;
  cursor: pointer;
}
02

Estilizar el track (línea de fondo)

Necesitas dos selectores: uno para Webkit (Chrome/Edge/Safari) y otro para Firefox.

/* Chrome, Safari, Edge */
input[type=range]::-webkit-slider-runnable-track {
  height: 6px;
  border-radius: 3px;
  background: #1e2640;
}

/* Firefox */
input[type=range]::-moz-range-track {
  height: 6px;
  border-radius: 3px;
  background: #1e2640;
}
03

Estilizar el thumb (círculo que arrastra)

El thumb también necesita dos selectores. En Webkit hay que compensar la altura manualmente.

/* Chrome, Safari, Edge */
input[type=range]::-webkit-slider-thumb {
  -webkit-appearance: none;
  width: 18px;
  height: 18px;
  border-radius: 50%;
  background: #3b82f6;
  margin-top: -6px; /* centra en el track */
  cursor: pointer;
  border: 2px solid #0d1117;
  transition: background 0.2s;
}

/* Firefox */
input[type=range]::-moz-range-thumb {
  width: 18px;
  height: 18px;
  border-radius: 50%;
  background: #3b82f6;
  cursor: pointer;
  border: 2px solid #0d1117;
}
04

Track de progreso (parte izquierda coloreada)

Chrome no soporta ::-webkit-slider-fill. El truco es usar JS para cambiar un gradiente en línea según el valor actual.

/* Firefox: parte llena del track */
input[type=range]::-moz-range-progress {
  background: #3b82f6;
  height: 6px;
  border-radius: 3px;
}

/* Chrome: se hace con JS al mover */
function actualizarTrack(el) {
  const pct = (el.value - el.min)
              / (el.max - el.min) * 100;
  el.style.background =
    `linear-gradient(to right,
      #3b82f6 ${pct}%,
      #1e2640 ${pct}%)`;
}
05

Estado :focus y :hover en Power BI

Power BI HTML Visual corre en un iframe. Los pseudo-estados funcionan igual que en el browser normal.

input[type=range]::-webkit-slider-thumb:hover {
  background: #60a5fa;
  transform: scale(1.15);
}

input[type=range]:focus {
  outline: none;
}

input[type=range]:focus::-webkit-slider-thumb {
  box-shadow: 0 0 0 3px rgba(59,130,246,0.3);
}
06

Errores comunes en Power BI

Tres cosas que rompen el slider específicamente en el HTML Visual de Power BI.

  • Olvidar -webkit-appearance: none — el thumb de Chrome queda sin estilo.
  • No poner margin-top negativo en ::-webkit-slider-thumb — queda descentrado del track.
  • Usar width y height sin box-sizing: border-box — el thumb se deforma si tiene border.
